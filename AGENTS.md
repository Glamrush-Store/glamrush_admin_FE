# Codex Project Instructions

You are building the Glamrush Admin frontend.

Rules:

- Follow SPEC.md strictly.
- Use Nuxt 3 Composition API.
- Use Pinia stores per feature.
- Never duplicate logic.
- Use reusable UI components.
- All API calls go through composables/apiClient.js.
- Use plain JavaScript (no TypeScript).
- Create a const file for endpoints
- Use PrimeVue components and PrimeIcons for UI.
- Use Tailwind CSS alongside PrimeVue for custom styling.
- Use PrimeVue Forms with Yup for form validation.

When unsure:

- Ask clarifying questions.
- Do not invent backend endpoints.
